## 买 VPS 之前，先把用途想清楚

内存是最容易成为瓶颈的参数，也最容易买多。按下面的区间对号入座就行，宁可先用一段时间再升级，也别一上来就顶配——大部分商家的升级操作都是即时的。

| 用途 | 内存下限 | 建议配置 |
| --- | --- | --- |
| 静态博客 / Nginx | 512MB | 1GB |
| WordPress 单站 | 1GB | 2GB |
| Docker 跑两三个容器 / n8n 自动化 | 2GB | 4GB |
| 数据库服务器 | 4GB | 8GB |
| 游戏服务器（20 人在线） | 4GB | 6GB 以上 |
| AI 推理（7B 模型本地跑） | 8GB | 16GB |

CPU 方面，1-2 核能覆盖大多数场景，除非要做编译、转码这类吃 CPU 的活。存储优先选 NVMe：它和机械硬盘在随机读写上的差距是上千倍的，跑数据库、Docker、PHP 站点时体感明显；纯挂代理和测试机的话，普通 SSD 也够用，没必要为用不到的速度加钱。流量按 1TB/月起步考虑就行，个人项目很难用完。

## 机房位置怎么选：国内用户要单独考虑

原则只有一条：机房选在离用户近的地方，而不是离你近的地方。选错区域平白多出 50-200ms 延迟，100ms 就已经能感觉到“慢”。

国内用户的情况复杂一点。RackNerd 的机房集中在美国，走普通线路，西海岸（洛杉矶、圣何塞）到国内的路由通常比东海岸好。挂爬虫、跑脚本、部署博客、轻度自用代理，这些场景晚高峰有点波动无所谓；但远程桌面、看视频这类对流畅度敏感的用法，普通线路晚高峰抽风是常有的事。

付款之前，先给商家的售前支持发一个技术问题（比如“能否开放 TUN 模块”），看响应速度和专业程度，这一步能过滤掉大半不靠谱的商家。RackNerd 有退款政策、全部套餐给 root 权限，年付的试错成本本来就低；实在拿不准，先从 $1.99/月的入门档试起。👉 [查看 RackNerd 月付入门套餐](https://bit.ly/my-rn)

开通当天建议做三件事：装好系统后加 1GB swap，1GB 内存的小机器尤其需要，一行命令的事（`fallocate -l 1G /swapfile && mkswap /swapfile && swapon /swapfile`）；把备份跑起来，rsync 加对象存储是最省钱的组合；确认 SSH 密钥登录正常后再关掉密码登录。

还有一条容易被忽略：看到“不限流量”“不限资源”的字眼，先去找公平使用条款。便宜套餐的超额处理一般就两种——限速到 1-10Mbps，或者按 GB 收费，搞清楚属于哪种，再决定要不要把生产业务放上去。

## 常见问题

**$10.99/年 的套餐性能真的够用吗？**
跑 Nginx 静态站、轻量 API、定时脚本、自用代理都足够。应付不了的是编译大项目和高并发，这类需求直接看 4GB 以上。

**RackNerd 能装 Docker 和 WireGuard 吗？**
能。它是 KVM 完整虚拟化，每个 VPS 有独立内核，Docker、WireGuard 和各种 VPN 服务端都能正常跑。买便宜 VPS 时优先确认 KVM 架构——OpenVZ 架构跑不了 Docker，内存还常常是共享超售的。

**流量用超了会怎样？**
主流做法是限速或按 GB 计费。RackNerd 促销套餐每月 1-8TB 的流量，对博客和脚本来说很难用完；要跑视频、下载站这类大流量业务，先确认商家的超额政策再上。

**年付和月付怎么选？**
年付单价低，前提是这家商家靠得住。第一年拿不准就先月付跑一个月，确认稳定后再转年付。别第一天就锁三年长约——这么干的人，后来都在凌晨搜“VPS 怎么迁移”。

**一定要 NVMe 吗？**
跑数据库、Docker、PHP 应用，NVMe 的随机读写优势是实打实的；挂 VPN 和测试机，普通 SSD 完全够，为用不到的速度多花钱没有意义。
